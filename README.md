# Aruvi Collection - Billing & POS System

A complete frontend-only Women's Dress Shop Point of Sale (POS) and Billing System built with HTML5, CSS3, JavaScript, and Tailwind CSS.

## Features
- **Frontend Only**: No backend required. Uses LocalStorage for data persistence.
- **POS Billing**: Add products to cart, apply custom discounts, generate bills.
- **Inventory Management**: Add, edit, delete, and track stock.
- **Invoice Generation**: Generate professional PDF receipts using jsPDF.
- **Dashboard & Reporting**: View today's sales and recent invoices.

## How to run
Simply open `index.html` in any modern web browser to start using the system.
